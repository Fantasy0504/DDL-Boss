# DDL Boss 战 v1.0.0

首个 Windows x64 MVP：把现实中的截止任务变成像素 Boss，通过完成子任务发起攻击。

## 下载与安装

下载本页附件 **Deadline-Dungeon-1.0.0-Setup.exe**，双击并选择安装目录。无需 Node.js 或开发环境，支持 Windows 10/11 x64。

首次启动含四个示例任务，可在设置中清除。关闭主窗口默认驻留系统托盘；完全退出请使用托盘右键菜单。

## 本版功能

- 米白四栏界面，三种原创像素 Boss 和巫师猫桌宠。
- 快速/完整创建 DDL，支持编辑、删除、子任务权重、撤销、搜索和筛选。
- 完成任务扣血、伤害动画、动态台词、截止狂暴、首次胜利奖励与 Boss 图鉴。
- 桌面透明悬浮窗、拖动、置顶、缩放、隐藏/恢复及主窗口联动。
- 本地 JSON 保存、原子写入、有效备份、损坏恢复、导入/导出。
- 基础成就、行动统计、独立演示模式。

## 验证

17 项核心测试通过；四种尺寸的浏览器界面验证通过；打包应用的双窗口通信、隐藏恢复、缩放、拖动、托盘驻留、JSON 导入/导出与重启持久化验证通过。

安装包尚未做代码签名。Windows 开机登录、多显示器实际热插拔与全新系统安装仍需目标环境人工验收。
