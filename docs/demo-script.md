# 约 75 秒演示脚本

演示前进入“设置 → 演示模式”，使用独立沙盒，不改真实任务。桌面悬浮窗显示真实任务，演示模式不向它广播沙盒数据；需要展示真实双窗同步时，可创建一个明确命名的测试任务并在结束后删除。

1. **0–10 秒**：展示米白四栏首页与像素骑士。“以前是 DDL 追着我跑，现在是我追着 DDL 打。”
2. **10–25 秒**：完整创建一个 DDL，添加三个子任务并设置权重。“每个现实任务，都能召唤一位 Boss。”
3. **25–35 秒**：顶部切换“狂暴 3h”，展示状态与台词变化。“越接近截止时间，Boss 越着急。”
4. **35–50 秒**：依次勾选子任务，展示伤害数字、HP 下降和最近动态。“真正的行动，就是最强的攻击。”
5. **50–60 秒**：完成最后一项，显示胜利结算，打开图鉴。“每一次胜利，都值得被记住。”
6. **60–75 秒**：退出沙盒。用真实测试任务演示桌面 Boss 拖动、悬停与主窗口完成子任务后的血量联动；关闭主窗口展示托盘驻留，再单击 Boss 恢复。“它安静地陪你工作，直到下一个 DDL。”

实际录制应展示真实操作；本文件是录制脚本，不是已生成的视频或 Kiro 使用记录。
