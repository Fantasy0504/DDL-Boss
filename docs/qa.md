# 实施与验证记录

## 环境与方法

- Windows，Electron 44.4.5，React / TypeScript / Vite。
- 本会话未提供 Browser 插件，使用 Playwright + 本机 Chrome 验证浏览器预览；Electron 使用 Playwright `_electron` 直接启动实际编译应用。
- 视觉基准：`docs/reference/user-reference.png`，1536×1024。辅助概念图 `docs/reference/concept.png`。
- 使用 `view_image` 直接检查用户参考、辅助概念和实际渲染截图。检查 1536×1024、1440×940、1100×680 与 390×844；主截图见 `docs/screenshot.png`。

## 自动验证

- 17 项单元/集成测试：加权 HP、撤销、极小权重、精确截止边界、跨天倒计时、首次奖励、重复结算、各奖励时间边界、快速创建、已击败任务加子任务、保留/删除图鉴、清示例、数据结构校验、不可变事务、本地重启、并发写入、备份恢复及失败写入保护。
- 浏览器流程：快速与完整创建 → 自定义权重 → 编辑备注 → 攻击 → 击败 → 撤销确认 → 再次击败不重复奖励 → 搜索/删除 → 图鉴保留 → 刷新持久化 → 演示狂暴且不改真实存储 → 设置 → JSON 下载 → 无效导入不覆盖 → 成就与统计。
- 浏览器页面身份正确，非空白，无 Vite 错误覆盖层，无控制台错误；四种尺寸无页面横向溢出，桌面尺寸下主攻击按钮完整可见。
- 桌面流程：沙箱 preload 无 renderer `require` → 实际 JSON 保存 → 主/悬浮窗口 HP 同步 → 置顶切换 → 隐藏恢复 → 缩放 → 关闭驻留 → 悬浮窗恢复主界面 → 拖动改变坐标 → 重启持久化。
- 导出/导入通过实际主进程文件 API 验证，测试替换系统文件选择器返回值，完成 JSON 往返及无效文件保护；不依赖人工点选系统对话框。
- 打包版使用 `release/win-unpacked/DDL Boss.exe` 独立启动，同样执行完整桌面验证，显式传入临时 `--user-data-dir`，不修改用户数据。

## 视觉对照与修正

- **布局**：保留导航、DDL 列表、中央 Boss、右侧进度/清单/动态四区域。修正最小尺寸下网格隐式高度挤出主按钮的问题。
- **字体**：Windows UI 使用 Segoe UI / Microsoft YaHei，数值使用 Consolas。放大宽屏标题与清单层级；移动端图标导航补齐可访问名称。
- **配色**：保持米白、炭黑、灰色描边、低饱和红绿；按钮保持炭黑，没有采用生成概念中的红色导航。
- **素材**：原创像素角色和低对比废墟背景。修正图集跨单元边界导致的披风裁切和猫周围杂像素。
- **反馈**：子任务勾选、HP、伤害数值、台词、最近动态保持一致；参考图血量示例不一致之处以 PRD 计算为准。
- **交互与可见性**：修正计时器刷新引起弹窗焦点重置的问题，检查原生窗口、窄屏和较低高度时按钮与表单可操作。
- **首屏文案**：导航、四个示例标题、子任务文案与主攻击 CTA 保留。独立战斗技能区按 PRD 改为任务统计和说明，日期动态生成，新增本地保存提示与示例标记为有意差异。

参考图的设计语言和主要结构已完成对照验证。角色为原创重绘，未逐像素复刻参考图；保留的界面差异均为上述规则一致性、可用性或原创素材取舍。

## 剩余人工检查

- 透明像素的真实系统点击穿透（自动测试覆盖蒙版逻辑及 Electron 窗口交互，但未在所有 Windows/GPU 组合中检查）。
- 无开发环境的全新 Windows 10/11 虚拟机安装、升级与卸载。
- 安装包数字签名和参赛视频录制。
